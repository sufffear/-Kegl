# Сохранение прогресса Шанталь

Игровое состояние Android сохраняется в приватном SharedPreferences
`chantal_progress`, ключ `snapshot`, формат JSON версии 1.

Один снимок содержит опыт, характер, монеты, энергию, усталость, долги,
покупки, снаряжение, расходники, сумку, летопись, текущий поход,
непрочитанную историю и окно награды. Запись одного снимка удерживает
связанные изменения награды вместе. Повторное принятие той же истории
блокируется до следующей перерисовки экрана.

Новая установка начинает с пролога, нуля походов, опыта и монет,
без демонстрационного инвентаря. Начальные особенности характера и настроение
остаются частью персонажа. Данные предыдущих сборок, которые существовали
только в памяти экрана, перенести после их исчезновения невозможно.

После успешной композиции SideEffect передаёт снимок в SharedPreferences.apply:
память процесса обновляется сразу, Android асинхронно завершает дисковую запись.
Это не гарантия сохранения последнего нажатия при мгновенном аварийном отключении
питания до записи. Версия снимка проверяется; нечитаемый снимок не заменяется
новым при открытии экрана.

Проверки:

```sh
gradle :app:testDebugUnitTest --tests 'com.example.Chantal*PersistenceTest'
```

Четыре проверки хранилища: новый профиль, незавершённый поход и история,
связанные награды/сумка/летопись, отказ при повреждённом или неизвестном формате.
Одна Compose-проверка: пролог и поглаживание, удаление экрана из композиции,
повторное открытие, сохранность опыта и запрет повторного начисления за ласку.

На коммите 8929eea все пять проверок, сборка APK и проверка сертификата прошли:
https://github.com/sufffear/-Kegl/actions/runs/42380223735

Проверки после принудительной остановки процесса, перезагрузки телефона и
обновления APK на физическом устройстве ещё предстоят. ZIP-архивы формата 2
включают снимок Шанталь; старый формат 1 при восстановлении оставляет её
текущий прогресс без изменений.
