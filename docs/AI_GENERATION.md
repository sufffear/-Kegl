# Шаг 4/8 — Gemini: запросы подключены, проверка на телефоне ожидается

ChantalStoryGeneration: краткая память (последние шесть событий), текущий регион,
NPC и характер; без статистики тренировок и без ключей. Ответ проверяется:
10–12 элементов предложений, три разных выбора, реакции и допустимая черта.
Числовое изменение черты задаёт приложение (+2), как и ID/награду/предмет.
Неизвестные поля, ссылки на несуществующие события и изменения мира отклоняются.
Проверка структуры не гарантирует литературного качества или отсутствия противоречий.

Пока предложения изменений мира должны быть пустыми. Применение предложений модели
после принятия игроком требует отдельного протокола и ещё не реализовано.
Транспорт внедряется интерфейсом; сетевой адаптер и явная кнопка Gemini описаны ниже.
Ошибка возвращает Unavailable, исходная история/память не меняются. Отмена сохраняется.

Google AI Pro в приложении Gemini и Gemini API — отдельные продукты. По проверенной
документации Google есть Free Tier для части моделей; конкретные лимиты зависят от
проекта/модели и показаны в AI Studio. Наличие подписки не означает оплаченный API.
Для старта предполагается отдельный бесплатный проект без биллинга. Ключ не передавать
в чат/репозиторий/APK. Владелец создал ключ; его ввод на телефоне и проверка квоты ещё не выполнены.

## Подключение Gemini

Добавлен HTTPS-адаптер generateContent, JSON MIME, ограничение ответа/времени,
без автоматических повторов и перенаправлений. Модель по умолчанию
`gemini-3.1-flash-lite`: на проверенной странице Google указана Free Tier;
доступность/тариф конкретного проекта приложение определить не может.
ID можно изменить. Проверенный STOP обязателен, обрезанный/блокированный ответ отклоняется.

Ключ вводится в меню Шанталь → Настройки ИИ и Лора. Хранится AES-GCM с ключом
Android Keystore, вне игрового снимка/архива; Android backup отключён и исключает prefs.
Удаление ключа доступно там же. Ключ не переносится на другое устройство.
Нет автоматического запроса или проверки ключа при сохранении настроек.

Короткая проверка подключения доступна в настройках отдельной кнопкой (явно отправляет один запрос).
История запрашивается кнопкой под обычной непрочитанной историей. Общий локальный лимит — один запрос в минуту.
Авторская цепочка/поручения/юбилейные главы не регенерируются этой кнопкой.
Во время запроса решения скрыты, есть отмена. Уход с экрана отменяет coroutine;
блокирующее сетевое чтение может завершиться позже, результат не применяется.
Старая история сохранена до успешного проверенного ответа. Награды и ID прежние,
получение текста не начисляет и не тратит энергию. Применение предложений модели пока
не включено: proposals обязан быть пустым. Это оставшаяся часть шага 4.

На Free Tier Google может использовать запросы/ответы для улучшения продуктов;
в запросе только игровая память, без статистики тренировок. API-ключ не даёт приложению
достоверной информации о биллинге: бесплатный проект без оплаты выбирает владелец.
Реальный запрос и ввод ключа на физическом устройстве пока не проверены.

## Исправление по обратной связи 142359

Подключение и модель — раздельные карточки и операции сохранения. Настройка модели
свёрнута, подробности квоты/данных свёрнуты. Убраны неактивные провайдеры, выбор
сложности/лора, который пока не участвовал в запросе, и отладочный просмотр стадии.
Игровые сохранённые значения этих настроек не удаляются. Остался переключатель черт.

Проверка ключа допускает печатные ASCII-символы, включая пунктуацию; исключает
кавычки, пробелы, управляющие символы. Старое ограничение буквами/цифрами могло
отклонять ключ до Keystore. Точная причина ошибки на скриншоте не установлена.
KEY_FORMAT и KEY_STORAGE теперь разделены, секрет в ошибке не отображается.
HTTP 404/429/403 при проверке подключения имеют разные сообщения.

Тест шифрования использует подставной AES-ключ: проверяет round-trip, новый IV,
отсутствие plaintext в prefs/игровом архиве, сохранность старого ключа при ошибке.
Это не заменяет проверку Android Keystore на устройстве владельца.

## Проба рассказа без ожидания (обратная связь 142334)

В настройках Gemini доступен «Пробная история · без ожидания». Открытие окна не
отправляет запрос. Отдельная кнопка запрашивает полноценный рассказ с текущей памятью
и характером; действует общий интервал в минуту. В пробе можно выбрать ответ и прочитать
реакцию. Нет записи журнала/фактов, изменения черт, выдачи наград или расхода энергии.
Закрытие удаляет пробу и отменяет coroutine; блокирующий запрос может завершиться позже,
но не применяется к игре. Пробный рассказ не заменяет непрочитанную игровую историю.

Усилена инструкция модели: конкретная проблема, действия, развязка, содержание слухов
и решение загадки, реплика Шанталь, решения по событиям рассказа. Это инструкция,
а не гарантия литературного качества; настоящий ответ оценивается владельцем.

Новые локальные обычные походы используют три авторских fallback-рассказа по 11
предложений с тремя решениями, без старого текста «поделился важными слухами».
Цепочка фонаря по-прежнему имеет приоритет. Старый журнал и уже сохранённая непрочитанная
история не переписываются. Поручения сохраняют собственный прежний обработчик.
