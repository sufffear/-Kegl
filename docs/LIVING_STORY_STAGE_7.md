База: b042558240e7f5421f1e62f0daa3d1bd9fd4faaa.

## Объём и согласованность

Включены этапы 1–6 и экономный пакетный запуск проверок. Новые игровые механики
не добавлены. Возраст по принятым основным приключениям: 0–9 / 10–49 / 50–99 /
100+. XP не ускоряет возраст; его формулы и данные не переработаны. Четыре
стадийных изображения сохранены; эмоциональные портреты отложены.

Основная модель — OpenRouter x-ai/grok-4.20. Запросы только вручную;
бесплатная локальная история доступна без запроса. Платных вызовов при подготовке
сборки нет. Ключи остаются в Android Keystore/зашифрованных настройках телефона.

## Однократный чистый старт

По согласованному решению владельца эта версия при первом foreground-запуске
очищает тестовый прогресс Шанталь и выполненные тренировки, включая старые
контрольные точки и замороженные даты. День/серия/энергия/история начинаются с нуля.
Сохраняются API-настройки и ключи, оформление/звук, личные программы, интервальные
шаблоны и определения тренировок; отдельная импортированная книга не удаляется.

Маркер `final-start-v1` фиксируется вместе с обнулением в транзакции Room.
Он не привязан к versionCode и не должен увеличиваться с версиями приложения.
Томбстоун агрегата запрещает повторный импорт старого SharedPreferences-save.
DataStore покрыт прежним recovery-журналом: до commit откатываются прежние
настройки/прогресс; после commit остаётся новая игра. Отказ записи не помечает
сброс успешным. Следующий запуск повторяет подготовку безопасно.

Операция вызывается MainActivity до создания игрового UI/координатора тренировок.
Повторный запуск и последующие обновления не удаляют новую игру. Явное ручное
восстановление старого архива допустимо и не перевзводит сброс. API-хранилища и
системный Keystore операция не открывает. Метаданные новых архивов используют
реальную версию BuildConfig вместо устаревшей константы 0.5.0.

## Команды проверки

- Адресно: `python3 scripts/check-android.py related BackupRestoreTest`.
- Инструменты: `python3 -m unittest discover -s scripts/tests -q`.
- Выпуск на GitHub: `python3 scripts/check-android.py release` — один запуск
  Gradle со всеми unit/Robolectric тестами и assembleDebug; затем apksigner
  проверяет единственного подписанта и прежний SHA256 сертификата.
- `git diff --check`; проверка applicationId/version через aapt готового APK.

Полная регрессия и упаковка не дублируются локально и в CI. Подробные логи
сохраняются в build/checks и в GitHub artifacts. Сборка — debug с постоянной
ранее установленной подписью; публичный Play Store release не создаётся.

## Проверки на телефоне: NOT RUN

`adb devices` не обнаружил подключённого устройства; эмулятора в SDK нет.
Автоматические проверки не объявляются аппаратной приёмкой.

1. Установить APK поверх 0.18.0: пакет/подпись совместимы; при первом открытии
   прогресс нулевой, ключ OpenRouter и личные настройки сохранились.
2. Пройти начало, выполнить тренировку, проверить энергию и свободные занятия
   (+5 против +10 основных), начать поход; приложение переживает закрытие/открытие.
3. После возвращения прочитать локальную/ИИ-историю, выбрать ответ и получить
   награду один раз. Повторно открыть, проверить журнал и память.
4. Проверить жесты карты, читаемость/крупный системный шрифт, звук/вибрацию,
   аудиофокус, погасший экран и фоновые ограничения телефона.
5. Экспорт/восстановление архива; следующий запуск не сбрасывает новую игру.
6. Реальную литературную оценку Grok/расходы API владелец проверяет отдельным
   ручным запросом. Автоматические тесты используют подставной транспорт.

main не сливается; PR/публичный GitHub Release не создаются. Выдача APK через
рабочую ветку/GitHub artifact соответствует ранее выбранному владельцем способу.
Финальная аппаратная приёмка и решение о переносе в main остаются за владельцем.
