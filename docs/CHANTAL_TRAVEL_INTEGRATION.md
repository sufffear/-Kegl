# Интеграция Шанталь и путешествий

Переработка AI Studio объединена с интерактивной картой и выбором следующего маршрута.
Снимок прогресса сохраняет прежние поля плюс preferredRegionId; снимки без этого поля
оставляют выбор маршрута самой Шанталь. Импорт резервной копии и последующие обновления
не обнуляют прогресс. Карта показывает посещения и последние три решения для каждого
места по реальной летописи; новые события автоматически не выдумываются.

Быстрые действия: сетка 2×2. Минимальный шрифт подписей 14sp; масштаб Android сохраняется.
Общая типографика остаётся системной SansSerif, как в переработке AI Studio.

Поход длится 60 минут. ChantalJourneyClock и внедряемый TimeProvider обеспечивают одинаковую
проверку в интерфейсе и обработчике. До срока завершение запрещено; непрочитанная история
блокирует новый старт; повторные действия проверяют актуальное состояние.

Уведомление — уникальная задача Android WorkManager, привязанная к времени старта.
При выполнении проверяются сохранённый поход, готовность и отметка уже доставленного
уведомления. Никакие награды/истории в фоне не создаются. WorkManager сохраняет работу
после перезапуска/перезагрузки; режимы экономии батареи могут отложить доставку.
Force-stop пользователем может подавить фоновые задачи до следующего запуска.
При первом походе на Android 13+ предлагается разрешение; отказ не блокирует игру.
Повторно разрешить уведомления можно через настройки Android.

Нажатие открывает вкладку Шанталь и закрывает старые модальные окна через обновление
экземпляра экрана. Состояние персонажа загружается из сохранения. Старый/заменённый поход
не порождает уведомления. Уже просроченные архивные походы не создают новое напоминание
при восстановлении. Настройки доставки не включаются в игровой архив.

Скриншоты и XML/HTML-отчёты выгружаются workflow как отдельный артефакт. Ошибки создания
снимков больше не подавляются. Проверки на физическом телефоне (жесты, масштаб, возврат
из уведомления при открытом приложении, разрешения и перезагрузка) остаются отдельными.
