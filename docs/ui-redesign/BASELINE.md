   при отсутствии `final-start-v1`. Для установленной RC1 с маркером повторного
   сброса нет, но обновление с версии без маркера пока опасно для новых требований.
   До поставки редизайна исключить автоматическое обнуление; маркер/сохранения не
   удалять и не перевзводить. Это отдельная согласуемая правка следующего этапа,
   сейчас код не менялся. Не предлагать установку RC1 ради создания backup.
2. Навигация: нет Статистики, настройки занимают нижнюю вкладку; нужно минимальное
   изменение существующих маршрутов, сохранение таймера и нормальный Back.
3. Домик/главная перегружены; искусственные взаимодействия реально найдены.
   Их согласованное скрытие — этап 4, без удаления данных/полезных действий.
4. Детали сумки/лавки находятся в ChantalModalMenuAndSections.kt, а не по старым
   номерам строк VelarisChantalScreen.kt. Переносить представление, не цены/обработчики.
