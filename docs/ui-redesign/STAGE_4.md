# UI/UX v2 — этап 4: главный экран Шанталь

База: локальные этапы 1–3 в feat/velaris-ui-cleanup, HEAD bc045f0.
Версия приложения и подпись не изменены. Этап 5 не начат.

## Изменено

- Домик разделён на ChantalHero, ChantalContextAction, ChantalQuickLinks,
  ChantalWorldMenu. На главной — имя/стадия, существующая иллюстрация с лаской,
  короткое состояние, одно основное действие, Сумка/История/Интерьер и Мир Шанталь.
  Высота иллюстрации зависит от экрана; быстрые ссылки при крупном шрифте
  располагаются вертикально. Новые портреты/ассеты не добавлены.
- Приоритет действия: награда → непрочитанная история → возвращение из похода
  → активный поход → подготовка. Используется прежний часовой таймер,
  без ускорения и автоматической генерации/выдачи наград при открытии страницы.
- Карта, лавка, история, настройки ИИ, развитие, интерьер, подготовка и поход
  открываются дочерними страницами. Старое меню из шести плиток поверх контента
  больше не используется. Оценки историй находятся в Истории, XP/черты —
  в Развитии, интерьер и снаряжение сохранили прежние реальные действия.
- В приложении Back закреплён в верхней панели; системный Back возвращает
  к родителю. Для каждой страницы сохраняется своя прокрутка. Страница
  восстанавливается при пересоздании Activity. Завершённые подготовка/поход
  не остаются под рассказом в стеке; устаревшая форма возвращает в домик.
- Убраны вызовы UI ручных привычек/приветствий и искусственного «Побыть с
  Шанталь». Старые поля homePresence/favoriteSnack/sharedGreeting/storyEmotion
  и их кодеки сохранены, включая уже записанную персонализацию. Нового чата нет.

## Границы и данные

Расчёт завершения похода перенесён в локальный callback без изменения тела;
компоненты отображения не считают награды. Выборы, подарки, покупки, ласка,
модальное окно награды и ручные запросы ИИ используют прежние обработчики.
Не менялись data/domain/service, Room/миграции, формулы энергии/монет/XP,
возрастные пороги, провайдер/ключи, backup/recovery и тренировки. Новый read-only
WorkoutJournalRepository относится к уже выполненному этапу 3.

Детали предметов в сумке/лавке намеренно оставлены прежними до этапа 5.
Существующие тесты сохранены, UI-переходы в них обновлены под новый маршрут.
