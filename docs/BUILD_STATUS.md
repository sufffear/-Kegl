## 2. Последний успешный APK и способ получения

- **Команда сборки, тестов и экспорта в папку релизов репозитория:**
  - `gradle :app:testDebugUnitTest :app:exportDebugApk` -> **`BUILD SUCCESSFUL`**
- **Готовый установочный файл APK в дереве проекта (вне `.gitignore`):**
  - **`releases/velaris-v0.3.0-s2-debug.apk`**
- **Совместимость обновления:**
  - Сохранены `applicationId = "com.velaris.app"` и тот же ключ подписи `debug.keystore`. Увеличен `versionCode = 3`. При установке на Samsung SM-S938B сборка `0.3.0-s2` обновит установленную версию `0.2.0-0b` поверх, без удаления приложения.
