## 2. Последний успешный APK и способ получения

- **Команда сборки, тестов и экспорта в папку релизов репозитория:**
  - `gradle :app:testDebugUnitTest :app:exportDebugApk` -> **`BUILD SUCCESSFUL`**
- **Готовый установочный файл APK в дереве проекта (вне `.gitignore`, старые сборки очищаются автоматически):**
  - **`releases/velaris-v0.4.0-v1.1-debug.apk`**
- **Совместимость обновления:**
  - Сохранены `applicationId = "com.velaris.app"` и тот же ключ подписи `debug.keystore`. Увеличен `versionCode = 4`. При установке на Samsung SM-S938B сборка `0.4.0-v1.1` обновит установленное приложение поверх, без удаления и без потери базы Room (`MIGRATION_1_2`, `MIGRATION_2_3`).
