## 2. Последний успешный APK и способ получения

- **Команда сборки, тестов и экспорта в папку релизов репозитория:**
  - `gradle :app:testDebugUnitTest :app:exportDebugApk` -> **`BUILD SUCCESSFUL`**
- **Готовый установочный файл APK в дереве проекта (вне `.gitignore`, старые сборки очищаются автоматически):**
  - **`releases/velaris-v0.6.0-v1.3-debug.apk`**
- **Совместимость обновления:**
  - Сохранены `applicationId = "com.velaris.app"` и тот же ключ подписи `debug.keystore`. Увеличен `versionCode = 6`. При установке на Samsung SM-S938B сборка `0.6.0-v1.3` обновляет установленное приложение поверх, без удаления и без потери локальных данных Room и DataStore.
