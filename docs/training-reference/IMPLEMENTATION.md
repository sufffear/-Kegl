# Тренировки — правый референс, сливовая палитра

Основание: два пользовательских JPEG, утверждён правый вариант 2.
Уточнение владельца: кампанию/день/её прогресс полностью исключить;
новая схема сейчас применяется только к тренировкам. Нижняя панель прежняя.

## Реализация

- ReferencePlum.kt: семантическая схема фона/поверхностей/текста/состояний,
  градиенты упражнений, периодов и кнопки ▶. Полная VelarisPalette и локальная
  Material darkColorScheme готовы для последующего использования в других
  разделах. В глобальные настройки/enum тем новая схема пока не добавляется.
- Пользовательский JPEG 1280×720 скопирован побайтно в drawable-nodpi/chantal_training_hero.jpg.
  nodpi предотвращает ненужное увеличение bitmap под экранную плотность.
  Новой девушки, генерации, зеркалирования и ретуши нет. ContentScale.Crop,
  Alignment.TopStart сохраняет голову при повороте; высота 180–220dp.
  Velaris/Тренировки справа на свободной тёмной области, лицо слева не перекрыто.
- Старой горной шапки на PLAN нет. Кнопка настроек встроена в hero. Белые
  значки статусной панели локальны для тёмного hero и восстанавливаются
  при уходе; цвет/состав/поведение нижней навигации не меняются.
- Реальные группы/зачёты, выбранный период и автоматический переход к следующему
  незавершённому. Выбор сохраняется при Back/пересоздании. Нет выдуманной кампании.
- 450 с — сумма сжатий, прямо подписанная в строке; полные времена 3:20, 2:30,
  5:50 берутся из DemoProtocolConfig.totalActiveDurationMs, с последним отдыхом.
- Собственные градиентные поверхности/контуры/статический bloom/векторные иконки,
  настоящие Compose Text и клики. Основная карточка 56dp минимум, растёт с шрифтом.
  Тело открывает новый read-only обзор, ▶ запускает прежний обработчик.
  Выполненные/заблокированные упражнения не стартуют, два быстрых клика
  не вызывают callback повторно. При 150% время справа над кнопкой.
- Четыре режима открывают существующий EditProgramDialog с соответствующим
  WorkoutBlockType. Изменения редактора ограничены новым trainingLayout=true:
  ширина/прокрутка для формы. До «Сохранить» в хранилище ничего не добавляется.
  Произвольная последовательность начинает с редактируемых шагов сжатия/отдыха.
- «Конструктор упражнений» открывает прежний каталог; его вкладки Пресеты и
  Интервалы сохраняют доступ ко всем прежним дополнительным занятиям и шаблонам.
  Старые UI-состояния каталога удаляются перед новым явным входом, не накапливаются.
- Общая вертикальная прокрутка. Ни горизонтального списка режимов, ни вложенной
  прокрутки на основном экране нет. Переносы длинных названий осмысленные;
  при крупном шрифте иконка периода над заголовком, без одинокой буквы в строке.
- Режим демо честно помечается в hero, когда он выбран в существующих настройках.

## Границы

Движок, ForegroundService, звук/вибрация, награды, DAO/схемы, модель прогресса,
API/ключи и история не менялись. Другие экраны не перекрашены. Изменения
VelarisScreen имеют прежние значения по умолчанию и новые отступы только для PLAN.
Релизный кандидат rc3 / versionCode25; предыдущий rc2 был 24. Подпись постоянная.

## Визуальная проверка

Реальные Compose-рендеры из Robolectric API28: app/build/reports/training-reference/.
Это не снимки физического телефона. Поддержаны обычный/150% шрифт; сравнивались
композиция, контуры, карточки, положение времени и отсутствие оборванных слов.
Цвета дополнительно сверялись с RGB чистых участков JPEG-референса. Численная
метрика «99%» не заявляется: JPEG/свечение/размер экрана не задают такой метрики.

Согласованные отличия: другая утверждённая иллюстрация, бренд справа, отсутствие
кампании и пояснительных панелей, прежние четыре нижние вкладки. При большом
шрифте применяется общая прокрутка, высота карточек и периодов увеличивается.

## Оставшиеся отличия от рисунка

- Тонкая строка длительности нейтральная, а не зелёная: зелёный сохранён
  только для выполненных состояний согласно текстовому требованию.
- Мелкий орнамент и характер иллюстрированного свечения воспроизведены
  упрощёнными нативными контурами/градиентами; полного совпадения пикселей нет.
- Обычный размер шрифта близок к референсу; 150% адаптирует высоты,
  переносы и положение иконок. Это намеренная адаптация для читаемости.
