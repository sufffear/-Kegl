# Память мира, первый слой

worldMemory версии 1 хранится внутри прежнего снимка Шанталь: events, promises,
relationships, magicItems, keepsakes. Общая версия снимка остаётся 1; отсутствие
поля допустимо. При чтении/сохранении старый принятый журнал переносится идемпотентно.
Непрочитанная история и история без выбранного действия фактами не становятся.
Краткое содержание пока является выдержкой до 600 символов, без внешней модели.
Полный текст остаётся в журнале. context отдаёт последние шесть событий (максимум 12).

Обещания/отношения/предметы создаются только явными подтверждёнными последствиями
через withFact. Эта функция возвращает проверенную копию; неизвестный источник,
будущая версия и четвёртое открытое обещание отклоняются. Магической вещи нужно
описание свойства. Удаления памятных вещей и штрафа за отсутствие здесь нет.
Неподтверждённый ответ будущей модели должен храниться отдельно от worldMemory.

Снимок экрана, который ещё не передаёт поле памяти, сохраняет существующую память.
Архивирование и восстановление используют весь снимок, поэтому память включена в
резервную копию. Старый архив без поля мигрируется по своему журналу, а не смешивается
с памятью заменяемой игры. Проверка будущей версии выполняется до замены данных.

Это слой хранения и проверки. Экран дел, поведение NPC, свойства конкретных предметов
и авторская цепочка появятся на следующих этапах. Предложений модели пока нет.
