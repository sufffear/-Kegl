## Провайдер и расходы
Основной выбор владельца: OpenRouter, x-ai/grok-4.20. Публичный /api/v1/models
перепроверен: ID существует, объявлены response_format/structured_outputs/reasoning.
Multi-Agent вариант не выбран. Не утверждаем доступность конкретного аккаунта
только на основании публичного каталога. MindStudio/backend/сервер не используются.

Ключ вводится на телефоне и хранится AES-GCM с Android Keystore; namespace
OpenRouter отделён от Gemini. Ключей нет в APK, игровом снимке или backup.
Сохранение ключа не вызывает сеть. Gemini остаётся явно выбираемой альтернативой;
автоматической смены модели или провайдера при ошибке нет.

Один POST по нажатию, без прикладных повторов и failover, локальный общий лимит
раз в минуту для проверки/preview/генерации. max_tokens4096, prompt до48000
символов, reasoning запрошен выключенным, web/tools не включаются. Ответ ограничен
128KiB, содержимое32k символов. Перенаправления запрещены; fixed-length streaming
не позволяет HTTP-клиенту повторно отправить буферизованный платный POST.
Cancellation закрывает соединение; это не гарантия возврата стоимости уже
отправленного запроса провайдером. Строгий денежный потолок задаётся владельцем
на стороне ключа/аккаунта OpenRouter, а не выдуманной гарантией бесплатных токенов.

## Игровая цепочка
1. После возврата готовится/сохраняется разрешённый план и короткий локальный
   рассказ. Запросов ИИ нет. Исходный эпизод сохранён в narrativeBinding.
2. Кнопка ручной генерации фиксирует token IN_FLIGHT и снимок контекста.
3. Модель получает голос3.3, реальную форму/возраст, разрешённый исход,
   неизменные варианты ответов, последние4 эпизода, до12 событий движка и до8
   важных прежних дел/отношений/магических свойств/памятных вещей с источниками.
   Полная летопись не отправляется.
4. ИИ возвращает только название, абзацы, реакции по индексам и ссылки.
   Неизвестные поля, ссылки и неверные индексы/границы отклоняются. Метки ответов,
   дельты черт, награды, loot, суммы и исходы принадлежат приложению.
5. Публикация проверяет token и стабильный fingerprint текущего эпизода.
   При отмене, повреждённом ответе, ошибке или superseded request сохранённый
   рассказ остаётся доступным. Перезапуск не возобновляет сеть автоматически.
6. Только выбор игрока одной Room-транзакцией принимает эпизод, награду,
   состояние движка, receipt и событие. Генерация/preview награды не выдают.

Fingerprint использует сортировку JSON-ключей и стабильное экранирование,
не порядок HashMap конкретной Android-версии. Импорт backup сбрасывает активный
сетевой token, поэтому поздний ответ до импорта не может перезаписать восстановление.

## Согласованность старой и новой игры
Начатая незавершённая цепочка фонаря резервирует основную линию; остальные
приключения в этот период самостоятельные. Если уже идёт новая основная загадка,
старая цепочка не запускается параллельно. Состояние с двумя активными основными
системами требует явного согласования, не тихого удаления старых записей.

Новый движок учитывает внешние принятые главы/сундуки без выдуманных канонических
событий. Кодек обновлён доv2, чтениеv1 поддержано. Это сохраняет правильный возраст
после юбилейных путешествий. Поручения остаются прежней локальной механикой и не
увеличивают счётчик основных приключений. Для сундука сохранены все существующие
варианты (в том числе4-й), денежные/XP/характерные формулы не менялись.

Подтверждённая сводка берётся из разрешённого исхода, не из свободного model summary.
Полное художественное изложение сохраняется в летописи. Проза всё ещё может
содержать смысловую ошибку — JSON-валидатор не доказывает литературную истинность.
Существующие свободные модельные proposals из старого pipeline не применяются
к новым связанным рассказам: последствия задаются движком.

## Как проверить на телефоне
Установить debug APK поверх текущей версии со штатным сертификатом (без uninstall).
Шанталь → меню → настройки ИИ → Grok основной → ввести личный OpenRouter-ключ.
«Сохранить» не отправляет запрос. «Проверить подключение» — один короткий платный
запрос. Через минуту можно открыть «Пробная история · без ожидания» и вручную
получить один рассказ: часовой поход для литературной пробы не требуется.
Preview не записывает историю/решение, не выдаёт энергию/монеты/XP.
Ключ в чат не присылать. Для отчёта об ошибке достаточно HTTP-кода/текста приложения.
