# Android: экономный цикл проверки

- Команды и выбор проверок: [docs/ANDROID_CHECKS.md](docs/ANDROID_CHECKS.md).
- Для небольшой правки — `python3 scripts/check-android.py changed`; сначала
  изучи выбор через `--dry-run`. Если зависимости изменения шире карты тестов,
  выбери `full`. Не повторяй отдельно компиляцию, уже включённую в тестовую задачу.
- Сохраняй все существующие тесты. Не ослабляй проверки, чтобы получить PASS.
- Полная регрессия обязательна при существенных/критичных изменениях,
  недостаточной уверенности локальных тестов и перед выпуском.
- APK — только по запросу или обоснованной необходимости (`release`).
  Обычный push не запускает упаковку APK.
- Один пакетный запуск; перед повтором анализируй ошибку. Не используй циклы
  повторных запусков, `clean` или `--rerun-tasks` без установленной причины.
- В контекст выводи итог/счётчики и нужный фрагмент ошибки; подробности читай
  адресно из `build/checks/`. В конце укажи проверки и факт сборки APK.
